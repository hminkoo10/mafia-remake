# 딜러 클립·초상 규격 (하위 에이전트 작업용)

웹은 `casino-web/public/dealers/` 아래 파일을 **있으면 자동으로** 쓴다. 파일이 없으면 다음 순서로 대체한다:
상황 클립 → `<id>-idle.webm` → `<id>.png` → `dealer.png`(소피아 사진).

## 파일 이름
| 파일 | 용도 | 재생 |
|---|---|---|
| `<id>.png` | 초상 (사진) | 영상이 없을 때, 그리고 사이드 패널 아바타(얼굴 부분을 CSS로 확대) |
| `<id>-idle.webm` | 대기 루프: 숨 쉬고 살짝 움직이며 카메라를 본다 | 무음, 루프, 6~10초 |
| `<id>-deal.webm` | 카드 나누는 동작 (슈에서 카드를 꺼내 앞으로 밀어 준다) | 카드가 시간차로 놓이는 동안(홀 카드 딜, 플롭/턴/리버) 루프 |
| `<id>-flip.webm` | 카드 뒤집는 동작 (쇼다운, 딜러 홀 카드 오픈) | 쇼다운/딜러 오픈 연출 동안 루프 |

`<id>`는 `src/casino/table.rs`의 `DEALERS` 목록: `sophia`, `mia`, `hana`, `lina`.
파일을 넣은 뒤 그 딜러의 `has_portrait`를 `true`로 바꾸면 12판마다 교대에 들어간다.

## 구도
- 원본 `casino-web/public/dealer.png`(1536×1024)와 **같은 카메라·같은 테이블·같은 조명**. 딜러가 화면 가로 중앙, 머리가 위쪽 30% 안에 오게 (`object-position: center 22%`로 잘린다).
- 테이블 아래쪽 45%는 좌석·카드가 덮이므로 중요한 동작은 화면 위쪽 55% 안에서.
- 클립 첫 프레임과 마지막 프레임이 자연스럽게 이어져야 한다 (루프 재생).
- 인코딩: WebM(VP9), 1536×1024 또는 1280×853, 24~30fps, 무음, 클립당 2~6MB 이하.

## 캐릭터
- 소피아(sophia): 현재 사진. 검정 치파오, 금색 파이핑, 올린 머리.
- 미아(mia), 하나(hana), 리나(lina): 같은 유니폼, 서로 다른 얼굴·머리 스타일. 각각 초상 1장 + 클립 3개.
