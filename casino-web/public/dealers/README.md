# 딜러 클립·초상 규격 (하위 에이전트 작업용)

2026-09-24: 소피아의 대기·딜링 고해상도 영상(WebM·MP4)과 영상 포스터 `sophia-video.jpg`가 들어 있다. 클립은 1536×1024다. 만드는 방법과 검수 결과는 `GENERATION.md`에 있다. 연출을 끄면 `sophia-video.jpg`를 정지 화면으로 쓴다. 원본 `sophia-table.png`는 `casino-web/tools/reference/`로 옮겼다.

`DealerBackdrop.tsx`는 클립을 미리 로드하고 준비된 영상으로 전환한다. WebM을 먼저 시도하고 MP4로 대체한다. 무드 변경 시 DOM을 새로 만들지 않으며, 숨긴 영상·백그라운드 탭에서는 재생을 멈춘다. 화면 제목 옆의 연출 버튼이 딜러 영상과 카드·칩 애니메이션을 함께 끄고 켠다(기본 켜짐, 브라우저에 저장). 실제 영상이 없으면 사진을 유지한다.

웹은 `casino-web/public/dealers/` 아래 파일을 있으면 자동으로 쓴다. 파일이 없으면 다음 순서로 대체한다: 상황 클립 → `<id>-idle.webm` → `<id>.png` → `dealer.png`.

## 파일 이름

| 파일 | 용도 | 재생 |
|---|---|---|
| `<id>.png` | 초상 (사진) | 영상이 없을 때, 사이드 패널 아바타 |
| `<id>-video.jpg` | 영상 포스터 | 영상이 뜨기 전 화면. 소피아는 `sophia-video.jpg` |
| `<id>-idle.webm` / `.mp4` | 대기 루프 | 1536×1024, 무음, ping-pong 3.2초 |
| `<id>-deal.webm` / `.mp4` | 카드 나누는 동작 | 약 0.9초 단일 카드 제스처. 카드마다 웹이 다시 시작 |
| `<id>-flip.webm` / `.mp4` | 카드 뒤집는 동작 | 소피아 플립 클립 없음. 웹은 대기 영상을 유지 |

`<id>`는 `src/casino/table.rs`의 `DEALERS` 목록: `sophia`, `mia`, `hana`, `lina`.

## 구도

- 원본 `casino-web/public/dealer.png`와 같은 카메라·같은 테이블·같은 조명. 딜러가 화면 가로 중앙, 머리가 위쪽 30% 안에 오게 (`object-position: center 22%`로 잘린다).
- 테이블 아래쪽 45%는 좌석·카드가 덮이므로 중요한 동작은 화면 위쪽 55% 안에서.
- WebM(VP9) + MP4(H.264, faststart), 3:2 비율(1536×1024), 24fps, 무음.
- 딜링 클립은 단일 카드 제스처만 담고 카드마다 다시 시작한다. 플립 클립은 소피아에 배포하지 않는다.

## 캐릭터

- 소피아(sophia): 검정 치파오, 금색 파이핑, 올린 머리. 고해상도 대기·딜링 클립 2종과 포스터 1장.
- 미아(mia), 하나(hana), 리나(lina): 같은 유니폼, 서로 다른 얼굴·머리 스타일. 각각 초상 1장 + 클립 3개.
